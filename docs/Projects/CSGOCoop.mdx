# CS:GO - Co-op Missions

A series of cooperative PVE maps for Counter-Strike: Global Offensive. This is where I got my start with modding!

These maps featured all sorts of cool things, like adding a player revive system that's entirely handled within Vscripts, the ability to barricade doors and windows with planks, and a class system with custom deployable gadgets.

[Steam Workshop Link](https://steamcommunity.com/id/moffein/myworkshopfiles/)

***With the release of Counter-Strike 2, these are no longer playable unless you downpatch your game to the Global Offensive era.***

I was responsible for level design in the Hammer Editor, as well as gamemode scripting both through Hammer Entity Logic and VScripts.
